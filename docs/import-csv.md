# 他の家計簿アプリからCSVを取り込む

OsidOri / Zaim / マネーフォワード ME / 銀行・カードの明細CSVを、
このツールの家計簿（`data/expenses.csv`）に取り込めます。

---

## 先に結論：自動連携はできません

| やり方 | 可否 | 理由 |
|---|---|---|
| **API連携（自動）** | ✗ | OsidOri に外部開発者向けの公開APIはありません |
| **画面の自動操作** | ✗ | 利用規約に触れる可能性が高く、アプリ更新のたびに壊れます |
| **CSV取り込み（手動）** | ✓ | OsidOri にCSV出力機能があります。**これを使います** |

つまり **「月に1回、CSVを書き出して取り込む」** という運用になります。
慣れれば1〜2分で終わります。

> **OsidOri の注意点**
> 1件ごとの取引明細CSVは**プレミアムプラン限定**です。
> 無料プランでは月次集計データのみで、期間も当月を含む7ヶ月前までです。
> 月次集計でも「今月いくら使ったか」は出せますが、
> 日別・店舗別の細かい分析はできません。
> 参考: [OsidOri サポート「csv出力とは何でしょうか」](https://support.osidori.co/hc/ja/articles/5559460712857-csv%E5%87%BA%E5%8A%9B%E3%81%A8%E3%81%AF%E4%BD%95%E3%81%A7%E3%81%97%E3%82%87%E3%81%86%E3%81%8B)

## ① CSVを書き出す

### OsidOri

1. ホーム画面 → 左上の **三本線（サイドバー）**
2. **便利な機能** → **データバックアップ**
3. 個人画面／家族画面、取得期間、集計期間を選んでダウンロード

### Zaim

Web版 → 設定 → データ出力

### マネーフォワード ME

Web版 → 家計簿 → 収入・支出詳細 → 月次データのダウンロード

ダウンロードしたCSVを、パソコンの分かりやすい場所（例: `ダウンロード` フォルダ）に置きます。

## ② まず中身だけ確認する（書き込まない）

**いきなり取り込まず、必ず `--dry-run` で確認してください。**

```powershell
python -m secretary import "$env:USERPROFILE\Downloads\osidori.csv" --dry-run
```

```
ファイル   : osidori.csv
文字コード : cp932
読み取れた列: 日付, 収支, カテゴリ, 中項目, 金額, メモ

列の対応（推測）:
  日付     ← 日付
  金額     ← 金額
  カテゴリ   ← カテゴリ
  中項目    ← 中項目
  メモ     ← メモ
  収支     ← 収支
  符号の扱い : 収支列で判定

取り込む件数: 5件  合計 51,900円
期間        : 2026-08-02 〜 2026-08-14
  除外 1件: 収入・入金
  除外 1件: 振替・振込

先頭5件:
  2026-08-02  食費             8,200円  スーパー / まとめ買い
  2026-08-05  交通費            3,400円  電車
  ...
```

**確認するのはここ3つです。**

1. **列の対応** が正しいか（日付が日付の列を、金額が金額の列を指しているか）
2. **合計金額** がアプリで見える金額と近いか
3. **除外された件数** に納得できるか（収入と振替は既定で除外します）

## ③ 問題なければ取り込む

`--dry-run` を外すだけです。

```powershell
python -m secretary import "$env:USERPROFILE\Downloads\osidori.csv"
python -m secretary money        # 反映を確認
```

**同じファイルを2回取り込んでも二重計上しません。**
日付・カテゴリ・金額・メモが同じ行は「すでに取り込み済み」として除外されます。
毎月まとめて出力して、そのまま取り込んで大丈夫です。

## 自動でやってくれること

- **文字コードの判別** — Shift-JIS（cp932）、UTF-8、BOM付きUTF-8 を自動で見分けます
- **列名の推測** — `日付/取引日/利用日`、`金額/支出/出金/利用金額`、
  `カテゴリ/大項目/費目` など、アプリごとの言い回しに対応します
- **符号の向き** — 支出をマイナスで書くアプリ（マネーフォワード等）と、
  プラスで書くアプリ（Zaim等）を自動で判別します
- **収入・振替の除外** — 給与や口座間移動は「使ったお金」ではないので除きます
- **金額の表記ゆれ** — `¥8,200` `8200円` `(1,234)` `１２３４` すべて読めます

## うまく推測できなかったとき

列名を直接指定できます。

```powershell
python -m secretary import kakeibo.csv --dry-run `
  --date-col "ご利用日" `
  --amount-col "ご利用金額" `
  --category-col "ご利用先"
```

| 症状 | 対処 |
|---|---|
| `金額の列を見つけられませんでした` | 出力された「読み取れた列」を見て `--amount-col` で指定 |
| `文字コードを判別できませんでした` | Excelで開いて「CSV UTF-8」形式で保存し直す |
| 合計金額がアプリと合わない | 収入・振替を除外した結果かもしれません。`--include-transfers` で振替も入ります |
| カテゴリが「その他」ばかり | `--category-col` でカテゴリの列を指定 |
| 収入まで支出として入った | 収支の列がないCSVです。`--amount-col` を支出専用の列に向けてください |

取り込んだ結果がおかしければ、`data/expenses.csv` をテキストエディタで開いて
該当行を消せば元に戻せます（ただのCSVです）。

## 運用のおすすめ

**月に1回、月初にまとめて取り込む**のが手間と正確さのバランスが良いです。

```
毎月1日:
  OsidOri でCSV出力 → import --dry-run で確認 → import で取り込み
日々:
  大きな買い物だけ python -m secretary add 食費 3000 メモ で足す
```

OsidOri 側は銀行・カードと自動連携しているので、
**現金以外はほぼ自動で貯まります**。このツールはそれを毎朝の通知に載せる役です。

固定費（家賃・光熱費など）は `config.yaml` の `fixed_costs` に書いておけば、
CSVに含まれていなくても引き落とし予定として通知されます。
