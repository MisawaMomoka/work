# 案件メールを判定して、Googleフォームで応募する

ココナラアシスト運営から届く案件メールを30分ごとに確認します。
**あなたの条件に合う案件だけ**、メールの「▼応募はこちら」にある Google フォームに、
**あなたの経歴をもとにした回答**を入れて応募します。結果は LINE などに届きます。

```
💼 案件メール 3件の結果

✅ 応募しました｜【新着】SNSマーケティングディレクター
案件: 採用広報のInstagram立ち上げ〜運用。週20h、リモート
判定: リモート可・SNS運用・単価条件を満たす
回答:
  ・稼働可能時間: 週20時間以上
  ・自己PR: 前職で美容サロンのInstagramを立ち上げ、…

📝 確認待ち｜【新着】ショート動画編集
※ 必須の質問に答えられません: 希望単価
▶ 回答を入れたフォーム（確認して送信を押すだけ）:
https://docs.google.com/forms/d/e/…/viewform?usp=pp_url&entry.…

⏭ 見送り｜【新着】テレアポ
見送り理由: 架電業務は対象外
```

## 安全のための決まり

- **プロフィールに書いてないことは答えません。** 経歴・実績・数字・希望単価をAIが作ることはありません。
  答えられない必須の質問があれば送信せず、「確認待ち」として回答入りのリンクを送ります
- 選択肢の質問は、フォームの選択肢と照らし合わせてから送ります。合わなければ送りません
- 差出人が設定の相手（既定: 名前かアドレスに「ココナラアシスト」を含む）のメールだけを見ます。
  **差出人アドレスがわかったら `from_addresses` に書いてください**。なりすましメールを確実に弾けます
- リンク先が Google フォームでなければ開きません
- 判定したメールには Gmail のラベル `job-checked` を付け、二度は応募しません
- 最初は `auto_submit: false`（送信はせず、回答入りのリンクを通知するだけ）で始めます。
  内容に納得できたら `true` にすると、自動で送信まで行います

## できないこと

- Googleアカウントでのログインが必要なフォーム（「失敗」として通知します）
- ファイルのアップロード、グリッド形式、時刻の質問（必須なら「確認待ち」になります）
- Googleフォーム以外の応募ページ

## セットアップ

### 1. プロフィール（経歴）を書く

AIが回答に使う唯一の材料です。**ここに書いたことしか答えません。** 次の形を目安に、
事実を具体的に書いてください（箇条書きでかまいません）。

```markdown
# 基本情報
- 氏名: 山田 花子（ヤマダ ハナコ）
- メール: xxx@gmail.com
- 電話: 090-xxxx-xxxx
- 居住地: 東京都
- ココナラのユーザー名: xxx

# 稼働条件
- 稼働可能時間: 週20時間（平日日中・土日も可）
- 開始可能日: 即日
- 希望単価: 時給2,000円以上 / 月額15万円以上
- 打ち合わせ: Zoom・Google Meet 可（平日10〜18時）

# 経歴・実績
- 2022〜2024 ○○株式会社でInstagram運用担当。アカウントを0から立ち上げ、1年でフォロワー1.2万人
- 2024〜 フリーランス。美容サロン3社のSNS運用代行（企画・投稿作成・分析レポート）
- ショート動画編集（CapCut・Premiere Pro）月20本

# スキル・ツール
- Canva / Photoshop / CapCut / Premiere Pro / Meta Business Suite / Googleスプレッドシート

# 自己PRで伝えたいこと
- 数字を見て改善提案するのが得意。月次レポートで…
```

### 2. 応募する条件を書く

```markdown
- 業務内容: SNS運用・Instagram・ショート動画編集・SNS広告。営業電話やテレアポは除外
- 報酬: 時給1,500円以上、または月額10万円以上
- 稼働: 週25時間以内
- 働き方: フルリモート（出社が必要なものは除外）
- 期間: 3ヶ月以上の継続案件
```

### 3. 手元で試す（送信も通知もしない）

プロフィールと条件を `data/profile.local.md` と `data/criteria.local.md` に保存します
（`.local.md` は Git に入らない設定なので、公開リポジトリに載りません）。

```bash
set -a; source .env; set +a      # SMTP_USERNAME / SMTP_PASSWORD / ANTHROPIC_API_KEY
python -m secretary apply --dry-run
```

直近2日の案件メールについて、判定・回答案・回答入りのリンクが画面に出ます。
**リンクを開いて、回答の中身が自分の言葉として出せるものか確認してください。**
違和感があれば、プロフィールを書き足すのが一番効きます。

### 4. 自動で動かす

1. GitHub →「Settings」→「Secrets and variables」→「Actions」に次を登録します
   - `JOB_PROFILE`: 手順1のプロフィール全文
   - `JOB_CRITERIA`: 手順2の条件全文
   - `ANTHROPIC_API_KEY`、`SMTP_USERNAME`、`SMTP_PASSWORD`（まだなら）
   - 通知先の設定（LINE なら `LINE_CHANNEL_ACCESS_TOKEN` / `LINE_USER_ID`）
2. `config.yaml` の `job_apply.enabled` を `true` にしてコミットします
3. 「Actions」→「案件メールに応募」→「Run workflow」で1回動かし、通知が届くか確かめます
4. しばらく「確認待ち」の通知で中身を見て、納得できたら `auto_submit: true` に切り替えます

> ⚠️ このリポジトリは**公開**です。プロフィールや条件を `config.yaml` に直接書かないでください。
> Actions のログには件数と結果の種類しか出さず、中身は通知先にだけ届くようにしています。

## 費用の目安

案件メール1通につき Claude API を1回呼びます。フォームの質問とプロフィールを読み、
回答を書くので、1回あたり数円〜十数円程度です。案件メールが来ない回は呼びません。
